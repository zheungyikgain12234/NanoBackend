## Per-page OCR confidence breakdown (for automated review)

How to read this: `engines` lists which OCR engine(s) actually ran on this page — a page with only one engine listed never got a second independent read to cross-check against, so a single engine's own confidence is the only signal available for it. `raw_confidence` is the engine's own self-reported confidence, averaged only over words it recognized — it says nothing about ink it never recognized as a word at all. `word_content_share` is the fraction of this page's real (non-structural) ink that ended up covered by a recognized word or an identified non-text artifact, versus ink left as unreliable handwriting/marks or not covered by anything — a page can show HIGH raw_confidence and LOW word_content_share at the same time, which means most of the page's real content never became text in the first place; don't read raw_confidence alone as "this page was read well" without checking word_content_share too. `adjusted_confidence` (raw_confidence × word_content_share) is the single number already shown as this page's confidence elsewhere in this document (frontmatter's mean_confidence is the average of these across included pages) — repeated here next to its own components so it's never the only number available.
